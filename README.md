Rainy Days

A multi-page e-commerce website for an outdoor jacket brand, with dynamic product data, a shopping basket, and a full checkout flow.

Built as a vocational school project for a front-end web development program.

Description

The Rainy Days website lets visitors browse jackets by gender/category, view detailed product pages, add items to a basket, and complete a multi-step checkout with a real, dynamically calculated order summary. All product data is fetched live from the Rainy Days API  and the basket persists across every page using localStorage.

Built with:
- HTML5
- CSS3
- Vanilla JavaScript (Fetch API, async/await)
- No frameworks

Features

- Dynamic product data fetched from the Rainy Days API (no hardcoded product data)
- Vanilla JavaScript with async/await (no .then(), no frameworks)
- Product filtering by gender/category
- Product detail pages with size selection
- Shopping basket with add/remove and quantity controls, persisted across pages via localStorage
- Multi-step checkout (Shipping, Payment, Review) with a real, dynamically calculated order summary
- Order confirmation page with a randomly generated order number
- Loading indicators and graceful error handling on all - API calls and asynchronous actions
- Mobile-first responsive design (mobile, tablet, desktop)
- CSS-only burger menu with dropdown navigation
- Semantic HTML5 structure
- GitHub Pages deployment

How to Run

Open index.html in a browser, or visit the live site via GitHub Pages. Requires an internet connection to load product data from the Rainy Days API.
